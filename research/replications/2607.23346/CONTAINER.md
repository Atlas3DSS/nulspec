# Containerized rerun

The container freezes the CUDA 12.8/PyTorch 2.9.1 environment used by four of
the five trials and checks out the exact upstream source commit. The dataset is
mounted rather than baked into the image.

The CUDA base is pinned both by the readable
`12.8.1-cudnn-runtime-ubuntu24.04` tag and its multi-architecture registry
digest `sha256:ac55d124...a1eb34bc`, resolved on 2026-07-31.
The Linux x86-64/Python 3.12 dependency closure is generated by uv and pinned
with package hashes in `requirements-replication.lock`; the human-maintained
top-level inputs remain in `requirements-replication.txt`.

```bash
docker build -t nulspec/sprkd:2607.23346 .

docker run --rm --gpus all \
  -v "$PWD/work/upstream/cell_images:/data/cell_images:ro" \
  -v "$PWD/outputs/container:/outputs" \
  nulspec/sprkd:2607.23346 \
  --data-root /data/cell_images \
  --output-root /outputs \
  --seed 0 \
  --epochs 500 \
  --teacher-epochs 2 \
  --n-teachers 3 \
  --batch-size 64 \
  --num-workers 4 \
  --progress
```

Run once per frozen seed 0–4. The dataset tree must match the manifest digest
in [SOURCE_MANIFEST.md](SOURCE_MANIFEST.md). NVIDIA Container Toolkit is
required on the host.

All Python runners and analyzers are included under
`/opt/sprkd-replication/scripts`. Override the entrypoint to run a frozen
extension or aggregate already-mounted outputs, for example:

```bash
docker run --rm --gpus all \
  --entrypoint python \
  -v "$PWD/work/upstream/cell_images:/data/cell_images:ro" \
  -v "$PWD/outputs:/outputs" \
  nulspec/sprkd:2607.23346 \
  /opt/sprkd-replication/scripts/run_extensions.py \
  --data-root /data/cell_images \
  --base-output-root /outputs/package-vs-intent \
  --output-root /outputs/extensions --seed 0
```

The citation audit is not embedded because its retained packets contain source
passages from third-party papers. Its derived result and per-trace digests are
part of the public study.

The workstation trial used the same Torch release with CUDA 13.0 wheels; GPU
runtime is retained in each trial's `config.json`. The CUDA 12.8 image is the
portable normalized environment, not a claim that the original authors used
this 2026 stack.
